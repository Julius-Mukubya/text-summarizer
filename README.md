# Text Summarizer

A text summarization app powered by [sshleifer/distilbart-cnn-12-6](https://huggingface.co/sshleifer/distilbart-cnn-12-6).

Paste any article or passage and get a concise summary. You can control the minimum and maximum length of the output using the sliders.
